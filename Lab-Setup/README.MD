Cybersecurity Lab Setup

A cybersecurity lab environment was created using VirtualBox to safely practice cybersecurity concepts. Kali Linux was configured as the attacker/testing machine, and a vulnerable target machine such as Metasploitable2 was used for security testing. A private Host-Only/isolated network was configured so that the machines could communicate without directly exposing the vulnerable system to the internet.

Tools such as Nmap, Wireshark, and Metasploit Framework were used to perform network scanning, packet analysis, vulnerability testing, and basic penetration-testing activities. The lab provides a safe and controlled environment for learning cybersecurity techniques without affecting real systems.
